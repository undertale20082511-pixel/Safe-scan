SAFESCAN 3.0 — ИНСТРУКЦИЯ

Файлы проекта:
- index.html — структура страницы и оформление интерфейса.
- app.js — проверка URL, QR-сканер, история, сравнение и TXT-отчёт.
- sw.js — Service Worker для кэширования файлов PWA.
- manifest.webmanifest — настройки установки приложения на телефон.
- icon.svg — иконка приложения.

ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Распакуй архив на компьютере.
2. Открой репозиторий GitHub.
3. Нажми Add file → Upload files.
4. Перетащи ВСЕ файлы из папки SafeScan_3_0 в корень репозитория (не саму папку и не ZIP).
5. Нажми Commit changes.
6. Открой опубликованный сайт. При обновлении подожди немного и обнови страницу.

Для камеры нужен HTTPS и разрешение браузера. Сканер загружает библиотеку html5-qrcode с CDN, поэтому для первого запуска сканера нужен интернет.

ВАЖНО: оценка — учебная эвристика по признакам URL. Приложение не обращается к полноценной базе фишинговых сайтов и не гарантирует безопасность. Низкий балл не означает, что сайт точно безопасен. Не открывай подозрительные ссылки.
